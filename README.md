# HBD-v3

A personalised birthday microsite for Anya, with animated headings and a sequence of sections leading to the main birthday message. Its warm visual style is designed as a small digital gift.

## Preview locally

Open `index.html` in a modern browser. For a local HTTP preview, run this from the repository directory:

    python -m http.server 8000

Then visit http://localhost:8000.

## Customising the page

The main experience lives in `index.html`. Keep text, colours, images, and animation timing consistent, and preserve the relative locations of referenced media files.
