# HBD-v3

A personalised birthday microsite for Anya, with animated headings and a sequence of sections leading to the main birthday message. Open the top-level `index.html` to view the birthday greeting and its warm, digital-gift presentation.

## Preview and review locally

Open `index.html` in a browser. For a local HTTP preview, run this from the repository directory:

    python -m http.server 8000

Then visit http://localhost:8000. After a change, review the text, colours, images, and animation timing together. Preserve the relative locations of referenced media files; if media is missing, check that its path still matches its location.

No hosting provider or provider-specific deployment steps are documented. Serve the page and its referenced media as static files, preserving their relative paths.
